_Un foyer permet de partager recettes, planning et liste de courses avec un proche. Voici comment inviter quelqu'un à te rejoindre._

## Le principe : un foyer, ça se partage

Au départ, tu es **seul dans ton foyer** — l'app affiche quelque chose comme **« Tu es seul·e dans ton foyer. Invite quelqu'un pour tout partager : recettes, planning et liste de courses. »** Inviter une personne, c'est l'ajouter à **ton** foyer pour que vous travailliez sur les mêmes données.

> 💡 Ce qui est partagé : **recettes, planning et liste de courses**. Ce qui reste personnel : tes **réglages de génération**, ton **prénom** et ton **avatar**.

## Générer un code d'invitation

Va dans **« Mon profil »**, section **« Mon foyer »**, et touche **« Inviter quelqu'un »**. L'app crée un **code d'invitation** de 8 caractères (par ex. `K7M2PQ9X`), affiché sous **« Code d'invitation »**, avec sa date de validité (**« Valable jusqu'au … »** — environ 7 jours).

## Trois façons de le transmettre

- **« Partager »** : ouvre le partage de ton téléphone (messages, mail…) avec un texte tout prêt et un lien d'inscription. _(Disponible si ton appareil le permet.)_

- **« Copier »** : copie le code seul ; un message **« Code copié »** confirme. Tu le colles où tu veux.

- **« QR code »** : affiche un QR code que ton proche n'a qu'à scanner. Re-touche (**« Masquer le QR »**) pour le cacher.

Le lien et le QR mènent ton invité vers une page d'inscription **pré-remplie avec le code** : il n'a rien à recopier.

## Régénérer un code

Besoin d'un nouveau code (l'ancien a fuité ou expiré) ? Touche **« Régénérer »** : un nouveau code remplace le précédent, qui cesse alors d'être valable.

> 💡 **Qui peut inviter ?** N'importe quel membre du foyer — pas seulement celui qui l'a créé.

## Et après ?

Quand ton invité rejoint, vos catalogues fusionnent. Si des recettes portent le même nom, l'app proposera de **faire le tri** (voir _J'ai été invité dans un foyer_). Le compteur de membres se met à jour : **« Vous êtes N à partager recettes, planning et liste de courses. »**
